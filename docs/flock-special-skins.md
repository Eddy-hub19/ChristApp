# Отара: 8 особых скинов (24–31)

Кристальная, кактус, грибок, лавовая, галактическая, грозовая, робот, суши. Статичные (без анимации), рисуются кодом
(`flockSpecialDeco.ts` + `flockCreature.ts`), кэшируются спрайтами как остальные платные скины. Цена 40 рубинов —
`FLOCK_CONFIG.rubies.specialSkinPrice` (`specialFrom: 24`). `NUM_SKINS` 24 → 32: номер скина по сети — `u8`, протокол не менялся
(тест кодека проверяет все 32 номера и 255). Боты берут только `FREE_SKINS` (0–11). В `HIDDEN_SKINS` не входят (в `main` этого флага нет).
